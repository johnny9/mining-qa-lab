# Plans

Use this directory for short-lived working documents during active development:
delivery sequencing, experiments, unresolved choices, migrations, and
coordination notes.

Plans are temporary. When work completes or a decision becomes durable:

- Move lasting intent, constraints, acceptance criteria, design decisions, and
  operational rules into the relevant feature specification.
- Update `specs/INDEX.md`, `specs/OVERVIEW.md`, or `specs/STORY-MAP.md` when the
  project-level picture changes.
- Delete or archive the plan according to the explicit request or repository
  policy.

Do not use a plan as the only record of supported behavior, a safety property,
an API contract, or an architectural decision.
